## Repository Structure

Each homework has its own directory (`HW1`, `HW2`, ...) containing:

- `code/` – scripts used for numerical/data analysis
- `derivations/` – handwritten or typed derivations
- `figures/` – plots and figures used in the report
- `report/` – final write-up (LaTeX source and compiled PDF)
